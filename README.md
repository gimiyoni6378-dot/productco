# SINI STUDIO

시니 스튜디오 공식 홈페이지 초안입니다.

## 구성
- `index.html`: 원페이지 소개 및 포트폴리오
- `styles.css`: 반응형 시네마틱 디자인
- `script.js`: 연도 표시, 포트폴리오 영상 모달, 문의 CTA

## 실제 오픈 전 교체할 항목
1. 포트폴리오 카드의 이미지와 작품명, 설명을 실제 작업물로 교체
2. `index.html`의 각 `data-video=""`에 공개 가능한 영상 URL 입력
3. `script.js`의 `CONTACT_EMAIL`에 실제 문의 이메일 입력
4. 외부 이미지 사용 여부 및 사용 권한 확인

현재 포트폴리오 영역은 샘플 레이아웃이며 실제 제작 사례를 의미하지 않습니다. 문의 메일과 실제 영상 URL은 제공되지 않아 임의로 만들지 않았습니다.

## 실행
정적 사이트이므로 별도 빌드 도구 없이 `index.html`을 브라우저에서 열면 됩니다.
