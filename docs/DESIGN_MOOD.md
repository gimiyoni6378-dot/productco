# 아이보리 시네마 무드

사용자가 2026-11-14 선택하고 재사용을 요청한 93seconds 프로그램 카드의 디자인 방향.

## 시각 기준
- 따뜻한 아이보리 카드와 밝은 베이지 바탕.
- 검정에 가까운 본문, 차분한 금색 가격과 라인 아이콘.
- 각진 테두리 대신 둥근 모서리와 은은한 그림자로 영역 구분.
- 정돈된 편집 디자인: 상품명 왼쪽, 가격 오른쪽, 얇은 구분선.
- 읽기 편하면서도 과하게 벌어지지 않는 간격.
- 불필요한 장식, 강한 테두리, 과한 그림자는 피한다.

## 현재 구현 토큰
- 섹션 배경: `#eeece6`
- 카드 배경: `#fbf9f5`
- 제목: `#171716`
- 본문: `#5c574f`
- 가격 및 포인트: `#85683f`
- 구분선: `#d7cec0`
- 할인 안내 배경 / 글자: `#f1e8d9` / `#74562f`
- 모서리: PC `24px`, 모바일 `22px`
- 그림자: `0 9px 20px rgba(48,40,27,.09)`
- 폰트: Noto Sans KR + DM Sans
- 아이콘: Phosphor Light 계열의 가는 선, 차분한 금색
- 카드 패딩: PC `clamp(22px,2.4vw,36px)`, 모바일 `24px`
- 레이아웃: PC 3열, 760px 이하 세로 1열

## 재사용 범위
색감·표면·타이포그래피·정렬·간격의 방향을 재사용한다. 새 페이지의 카드 수와 내용, 동작은 해당 요청에 맞게 정한다.
현재 프로그램 카드는 이동 없는 정적 안내이며, 배우 포트폴리오 카드 안에 독백·베이직·프리미엄과 옵션을 묶는다.

## 기준 구현
- `styles.css`의 `Ivory program cards` 구역
- `index.html`의 `#programs`
- 반영 커밋: `4d5792e25be0ad89e8af69281c96bbae71cbcf74`

사용자가 “아이보리 시네마 무드”, “전에 만든 아이보리 카드 느낌”을 요청하면 이 문서와 현재 구현을 기준으로 삼는다. 별도 지시가 없는 한 사이트 전체를 이 스타일로 자동 변경하지 않는다.
